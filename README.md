# Win721 Defender Manager

**Win721 Defender Manager** is a lightweight Windows utility developed by **721PC-Net Corporation**, designed to help users manage Windows Defender and Windows Update settings through a simple and convenient interface.

The software is part of the 721PC software ecosystem, providing users with convenient tools and services for managing their Windows systems.

## Features

- **Windows Defender Management**
  - Enable or disable Windows Defender.
  - Manage Real-time Protection.
  - Control selected Windows security features.

## Win721 Defender Manager console
  
Commands:

  Win721DM.exe /on defender
  
  Win721DM.exe /off defender
  
  Win721DM.exe /on winupdates
  
  Win721DM.exe /off winupdates
  
  Win721DM.exe /exclusions ('<path>' or "<path>")
  
  Win721DM.exe /unexclusions ('<path>' or "<path>")

## Supported Operating Systems

- Windows 7
- Windows 8
- Windows 8.1
- Windows 10
- Windows 11

*Note: Available features may vary depending on the Windows version and edition.*

## Requirements

- Windows 7 / 8 / 8.1 / 10 / 11
- Administrator privileges
- .NET Runtime (if required by the application)

## Installation

1. Download the latest release from the [Releases](../../releases) page.
2. Extract the downloaded archive.
3. Run `Win721 Defender Manager.exe` as Administrator.
4. Select the settings you want to manage.

## Usage

1. Launch Win721 Defender Manager with Administrator privileges.
2. Choose Windows Defender or Windows Update.
3. Enable or disable the desired features.
4. Apply the changes.
